# Linear Takeoff Competitive Analysis (pipe / duct / conduit / cable runs off PDF drawings)

**Date:** 2026-09-16. **Method & caveats:** Facts were gathered via web search excerpts of vendor help centers, release notes, press releases, review sites and forums. Direct fetches of vendor domains (trimble.com, constructconnect.com/atlassian KB, support.bluebeam.com, kreo.net, etakeoff.com, ibeam.ai, ductiq.ca, canaveral.ai, capterra.com, g2.com, reddit.com) were blocked by the network proxy in this session, and the search budget was exhausted before every gap could be closed. Where a vendor page is vague or a claim is second-hand (review site, competitor blog), I say so. Reddit threads could not be retrieved; forum-style evidence comes from G2/Capterra reviews and Bluebeam Community posts surfaced in search.

---

## 1. Product-by-product findings

### 1.1 Trimble AutoBid Mechanical (pipe/plumbing) — MEP-specific, desktop

- **(a) Linear tools:** Takeoff is "route line" based: you touch points along the pipe route with a mouse (OnScreen View) or digitizer; the product "generates all fittings, including branch takeoffs, based on the relationship between points that are touched" and "fittings are automatically generated while touching points along the route line in OnScreen View" (https://www.trimble.com/en/products/trimble-autobid-mechanical). The official "Takeoff Commands" video lists the command vocabulary: *Start New Run With Items, Vertical Run Only, Editing Items, Branch From, Branch From With Elbow, Branch With Elevation Change, Branch From Existing Mains, Add-Drop And Rise, Multi-add Drop or Rise, Change Elevation, Multi-branch Pairs, Multi-branch Pairs With Elbow 90, Area Takeoff, Count Mode, Length Takeoff, Branch In Vertical, Valve Takeoff, Connect/Reconnect* (https://videos.trimble.com/mep/demos/watch/h3J7hjUCaGEbtdQ2T2KU98?chapter=1 ; https://www.youtube.com/watch?v=_1RdTtGn_oQ). A separate "What's New 2020v1 – OnScreen View Takeoff" video exists (https://www.youtube.com/watch?v=9LhdJHJBdYM).
- **(b) Auto/assisted detection on vector PDFs:** None found. OnScreen View is click-driven; no snap-to-vector or auto-follow was documented in anything surfaced. (Not verified either way from release notes at https://stg-mepsupport.trimble.com/sites/mep.trimble.com/files/release_notes/ABMC%202019v2%20Release%20Notes%20-%20Final.pdf — blocked.)
- **(c) Size:** Size is a property of the run/spec; hangers are generated "at user-defined spacing based on pipe size" (Trimble product page above). A third-party description: "define a route line … a 100-foot run of copper piping that turns a corner — the software's … predefined rulesets automatically add the required pipe, the 90-degree elbow fitting, and the necessary hangers spaced at the correct intervals" (https://constructioncoverage.com/takeoff-software). Per-segment size change mid-run: implied by the "HotSpot" concept in the sister product (see SheetMetal) but not directly verified for Mechanical.
- **(d) Fittings:** Automatic at direction changes, branches ("Branch From", "Branch With Elevation Change"), and rise/drop ("Add-Drop And Rise", "Multi-add Drop or Rise") — the richest vertex-fitting vocabulary found in any product.
- **(e) Assembly math:** "identifies which pieces of pipe and fittings are connected. This generates hangers at changes in directions and at user-defined spacing based on pipe size"; labor from built-in MCAA/PHCC units (Trimble page; constructioncoverage.com).
- **(f) Scale:** not documented in surfaced material (unverified).
- **(g) Exports:** not documented in surfaced material (unverified).
- **(h) Pricing/complaints:** No public price (https://www.capterra.com/p/193710/AutoBid/pricing/). Capterra 4.4/5 from 17 reviews; cons quoted: "Click accuracy can be a little funky", "sometimes multipliers change and there is no notification", "very expensive … so companies can have more seats", "doesn't self-update … requiring purchase of a service pack" (https://www.capterra.com/p/193710/AutoBid/reviews/).

### 1.2 Trimble AutoBid SheetMetal (duct) — MEP-specific, desktop

- **(a)/(d):** Same route-point engine: "generates all fittings, including branch takeoffs, based on the relationship between points that are touched with either a digitizer or a mouse" (https://www.trimble.com/en/products/trimble-autobid-sheetmetal). Videos: "Takeoff Commands" (https://www.youtube.com/watch?v=AqXxClfyKKY), "On-Screen View Branches" (https://www.youtube.com/watch?v=M8ldEnIKBgM), "2020v1 What's New – OnScreen View Takeoff" (https://www.youtube.com/watch?v=pNFvrmRMiU0).
- **Per-segment change points:** A Trimble manual defines a "HotSpot" as "a mark in the duct run that indicates you have touched a place in the run, but did not change direction, elevation, or size" — i.e., the run model distinguishes points that change direction / elevation / size from those that don't (https://silo.tips/download/trimble-navigation-limited-all-rights-reserved). This is the clearest evidence of a size-change-at-vertex data model.
- **(c) Size / pressure class / gauge:** Pre-built database of rectangular, round and oval duct; "industry-standard labor units, including SMACNA, are built in"; "specification-driven takeoffs" (Trimble page; https://sourceforge.net/software/product/AutoBid-SheetMetal/). The exact UI for choosing pressure class/gauge per run was **not verifiable** from surfaced material — the vendor page is vague.
- **(e):** SMACNA labor; specs drive gauge/joint (implied by "specification-driven"; not detailed).
- **(f)/(g):** not surfaced (unverified). **(h):** same pricing opacity as Mechanical.

### 1.4 FastEST FastPIPE / FastDUCT / FastWRAP — MEP-specific, desktop

- **(b) Assisted detection — "Auto Connect":** "When you takeoff a pipe fitting, the software scans the physical plan to detect if there is a line between that fitting and another (and validates that the connection makes sense for the type and size). If it passes the test, the software will automatically takeoff the appropriate length of pipe between the two fittings" (https://fastest-inc.com/FastPIPE). FastDUCT is marketed with "onscreen takeoff with auto-connecting pipe & duct" (https://platform.softwareone.com/product/fastduct/PCP-3285-9376); training video "Mastering Autoconnect" (https://www.youtube.com/watch?v=-z8XgaF5WMg). This is fitting-first (place fittings, software fills pipe) rather than line-first — a genuinely different paradigm.
- **(a)/(c):** FastPIPE "calculates linear feet, diameter inches, weight, surface area, volume, material costs and labor hours … with a single click"; "hundreds of built-in HVAC and plumbing assemblies"; catalog "over 150,000 items" incl. hangers (FastPIPE page). FastDUCT: "calculates pounds, square feet, material costs, shop and field labor hours"; rectangular/round/oval; "Specs … customized for each duct system within a job … sheet metal raw materials, duct liner, joints, and stiffeners"; "assemblies that can be scaled directly on the plan … accept user-defined parameters, allowing you to change components during takeoff"; 250,000-item catalog; rect-to-round conversion (https://fastest-inc.com/FastDUCT ; https://softwarefinder.com/construction/fastduct-software).
- **(d):** FastDUCT user review: "some software has an option to auto select elbows, which FastDUCT does not currently offer … this can be time consuming" (https://www.capterra.com/p/105824/FastDUCT/reviews/). So fittings are placed manually in FastDUCT (with Auto Connect filling duct between them).
- **(e):** New-features page reportedly lists "Riser Hanger Support" and "Minimum Hanger Spacing" (https://fastest-inc.com/Features — surfaced only via search summary; not directly verified). FastWRAP imports FastPIPE/FastDUCT takeoffs for insulation and separates labor "based on … typical linear feet/day (piping) and square feet/day (duct)" (https://fastest-inc.com/FastWRAP).
- **(f):** Competitor claim (Beam AI): FastPIPE "has no built-in check for scale inconsistencies between a plan's stated scale and what's actually drawn" (https://www.ibeam.ai/blog/why-top-mechanical-contractors-are-replacing-90s-estimating-tools) — competitor source, unverified.
- **(g):** not surfaced (unverified).
- **(h):** $4,995 one-time or $79/mo (FastPIPE); FastPIPE+FastDUCT $7,490 or $355/mo; cons: "could use a makeover to appear more modern," "dual screen feature … cumbersome," EULA restricts use of outputs for AI training (https://fervorstudio.ca/news/fastpipe-review-pricing-alternatives/). McCormick's competitor review: https://www.mccormicksys.com/blog/fastpipe-review-for-plumbing-mechanical-contractors-features-pros-cons-alternatives/.

### 1.7 Bluebeam Revu (21.x) + Bluebeam Max — general PDF, the de-facto baseline

- **(a):** Length, Polylength (SHIFT+ALT+Q), Perimeter, Dynamic Fill. Polylength has a **Rise/Drop** field: "the value entered represents the total amount of rise and/or drop and will be added to the length total … Rise/Drop is mutually exclusive with Depth" (https://support.bluebeam.com/user-manual/menus/tools/polylength-measurement.html). Curved segments are supported on polylines/polylengths (arc conversion) — surfaced generically in guides (https://www.brightergraphics.com/guides/bluebeam-revu-poly-length-measurement).
- **(b):** **Snap to Content** — "only snaps to vector content in a PDF file. It will not snap if the content is an image or a scanned file" (https://support.bluebeam.com/revu/how-to/disable-snap-to-content-in-measurements-panel.html ; https://support.bluebeam.com/revu/troubleshooting/issues-with-raster-based-pdfs.html). **Dynamic Fill** detects closed boundaries on the content layer and can create "Space, Polygon Markup, Area Measurement, Polylength Measurement, and Perimeter Measurement"; settings for Fill Speed and edge/boundary sensitivity (https://support.bluebeam.com/user-manual/menus/tools/dynamic-fill.html). No click-to-follow-a-line tool. **Auto Align** (Revu 21, April 2024) is AI alignment for Overlay/Compare, not measurement (https://www.forconstructionpros.com/construction-technology/site-layout/product/22893273/bluebeam-software-inc-bluebeam-adds-auto-align-to-revu-21-construction-software ; https://press.bluebeam.com/2024/04/bluebeam-releases-new-ai-product-feature-in-april-update/).
- **Bluebeam Max (announced Oct 2025, global May 19, 2026):** "Magic Markups" = Duplicate as / Convert to / Offset ("Offset a line to create parallel markups at precise distances, CAD-style"); Claude natural-language integration; AI-Review/AI-Match (Firmus); Stitching of multi-sheet linear infrastructure. **No AI auto-measure of lines/pipes** (https://press.bluebeam.com/2025/10/bluebeam-unveils-bluebeam-max-next-generation-ai-powered-innovations-at-unbound-2025/ ; https://press.bluebeam.com/2026/05/bluebeam-max-launches-globally-bringing-ai-powered-productivity-to-aec-teams-everywhere/ ; https://blog.bluebeam.com/bluebeam-max-for-builders/ ; https://www.brightergraphics.com/guides/offset-magic-markup-in-bluebeam-max). Revu 21.6 (June 3, 2025) added markups on Capture; later notes mention MCP workflows and Stitching improvements (https://community.bluebeam.com/discussion/5556/whats-new-revu-21-6-updated ; https://support.bluebeam.com/revu/resources/revu-21-release-notes.html).
- **(c):** Size lives in the tool-set item (subject/label/custom column) — one tool per size; no per-segment size change within a polylength.
- **(d):** None native. Community request: "Add Counted items to a Poly length Measurement" asks to attach counts (pipe straps, anchors) to a polylength (https://community.bluebeam.com/discussion/964/add-counted-items-to-a-poly-length-measurement/p1). Third-party ZenEstimate HVAC add-on "can determine the type and number of hangers needed on each run" (https://zentekconsultants.net/zenestimate-tools/).

- **(g):** Markups List CSV/XML; Quantity Link to Excel (Complete/Max) (https://ncored.com/blog/bluebeam-revu-cost-2026.html).

## 3. What the best-in-class does (strongest capability per row, and who has it)

- **a. Linear tools — AutoBid Mechanical.** A run is a first-class object with commands for *Vertical Run Only, Branch From (with elbow / with elevation change / from existing mains), Add-Drop And Rise, Change Elevation, Branch In Vertical, Connect/Reconnect* (Trimble Takeoff Commands video). Nobody else models 3-D routing intent this richly on a 2-D drawing. STACK's *Split* tool and OST's per-segment Drop/Run box are the best general-purpose equivalents.
- **b. Assisted detection on vector PDFs — eTakeoff SnapAI (mainstream) and Canaveral/PixelTakeoff (new).** SnapAI "instantly grab[s] corner points or entire line measurements" from vector data with no PDF prep (etakeoff.com/Help/Snap.html). PixelTakeoff's *Auto Line* and *Dashed Trace* do one-click line capture including dashed runs. Trimble's 2026 "auto-routing" is the only announced automatic conduit-length feature in an enterprise estimator, but its mechanism is undocumented. FastEST *Auto Connect* is the best fitting-first assist (validates that a drawn line connects two fittings of compatible type/size).
- **c. Size — Canaveral (reads size text) and AutoBid SheetMetal (HotSpot model).** Canaveral is the only tool found that reads duct size annotations off the drawing and lets you accept them with a keypress; AutoBid's run model explicitly distinguishes vertices that change "direction, elevation, or size."
- **d. Fittings — AutoBid, Estimation Desktop, QuoteSoft, Canaveral.** Trimble inserts "90s, 45s, and tees along with continuous lines and drops/risers"; QuoteSoft's *Auto Elbow* both inserts the elbow and deducts its centerline length from the run; Canaveral derives "elbows at angle changes, tees at branches, reducers at size transitions."
- **e. Parts-per-LF — FastEST/QuoteSoft/AutoBid.** Hanger count from spacing (and "riser hanger support", "minimum hanger spacing" in FastPIPE), hanger "drop," liner/wrap and gauge/joint/seam per spec, SMACNA/MCAA labor; QuoteSoft exposes an "assembly audit trail." STACK's formula language ([MeasuredLinear]/10, waste %) is the best general-purpose model.
- **f. Scale — Bluebeam Viewports** (multiple regions per page, separate X/Y scales, calibrate) plus Trimble's AI auto-scale/name across a set.
- **g. Exports — Bluebeam** (Markups List CSV/XML, live Quantity Link to Excel, Legends) and Kreo's Auto Measure API.
- **h. Trust/QA — DuctIQ and Drawer.ai** publish the right posture: surface low-confidence runs, flag "unusual conduit runs," and require review; ConstructConnect's own guidance says spot-check linears and fully review curves/odd angles.

## 4. What nobody does well yet (gaps an industry-leading implementation could own)

1. **Click-to-follow a vector run with size-change awareness.** SnapAI grabs a polyline; Canaveral reads sizes; AutoBid models size-change vertices — but no product combines *auto-follow the centerline → read the nearest size tag per segment → split the run at each size change → insert reducers/transitions*. This is the single biggest open opportunity (all evidence above; no vendor documents the combination).
2. **Double-line ductwork centerline extraction on vector PDFs interactively.** DuctIQ/TaksoAi do it in batch with review; Bluebeam/PlanSwift/OST/STACK do nothing; Canaveral is "assisted." An interactive, explainable centerline from two parallel duct lines (with width → size inference cross-checked against the "12x8" text) is unclaimed.
3. **Deterministic, auditable fitting inference with rules users can see and override.** AutoBid and QuoteSoft generate fittings but reviewers complain of silent behavior ("multipliers change and there is no notification"); Procore over-applies drops "at every change in direction." Show the rule that fired at each vertex (angle threshold → 90/45, branch → tee/wye, size delta → reducer), make thresholds editable, and never double-count at tees.
4. **Rise/drop as geometry, not a scalar.** Bluebeam adds a single Rise/Drop number to total length; OST/STACK/Procore attach a drop per segment; STACK users hit a double-click-adds-drop bug. A per-vertex elevation attribute (with typed drops: riser to fixture, offset, rise-to-ceiling) that generates both vertical length and the fittings for it is missing outside AutoBid.
5. **Hanger/support logic that respects the run graph.** Only AutoBid documents hangers "at changes in directions and at user-defined spacing based on pipe size"; FastPIPE has riser hangers and minimum spacing. Nobody documents code-based spacing tables (e.g., by material/size) with per-run overrides and vertical-riser support rules exposed in the UI.
6. **Multi-scale per sheet + automatic scale sanity.** Bluebeam viewports exist but are manual; PlanSwift/Buildertrend/STACK require duplicating pages; ConstructConnect's Auto Scale is "planned Aug 2026"; Trimble has AI auto-scale. A dimension-string cross-check ("stated scale vs. drawn dimension") is called out as absent in FastPIPE by a competitor and not claimed by anyone as a first-class feature.
7. **Per-size legend with live run aggregation.** Bluebeam Legends total per tool; MEP tools total in the estimate. A takeoff-side panel with rows per system/size showing LF, fittings, hangers, insulation SF, labor, confidence, and "unreviewed AI" flags — updating as you draw — is not documented by any vendor.
8. **Insulation and pressure testing as per-run derived items.** FastWRAP is a separate module; QuoteSoft has liner/wrap per spec. Deriving insulation surface area by size/thickness and per-run items (pressure test, labeling, firestop at penetrations) directly from the run object is not surfaced anywhere.
9. **Published, reproducible accuracy for linear MEP.** Accuracy numbers exist for walls/floor plans (STACK within 3%; Togal 98%; Handoff 81.6% benchmark) and for Trimble time savings (60%), but no vendor publishes LF or fitting-count accuracy for pipe/duct on a public benchmark.

## 5. UX conventions to match (the de-facto flow)

- **Point entry:** click to place each vertex; **double-click the final point to end** (Bluebeam, PlanSwift, OST, STACK); Bluebeam also accepts **Enter**; Autodesk (Navisworks-era) uses **right-click** on the last vertex. STACK: "one click to start, one click for every turn, and double click to finish."
- **Undo last point:** **Backspace** (Bluebeam, PlanSwift, OST); PlanSwift also Ctrl-Z.
- **Ortho:** **Shift** constrains to 0/45/90° (Bluebeam, Autodesk); PlanSwift has an Ortho toggle where **Shift temporarily overrides** it.
- **Snap:** Bluebeam Snap to Content (vector only) toggled in the Measurements panel; eTakeoff SnapAI snaps to points/"logical lines"/polylines.
- **Continue / stay in mode:** PlanSwift and OST "Continuous Mode" keep recording after a double-click; OST **Esc** exits continuous mode.
- **Curves:** OST right-click segment → "Set as Curved Segment"; Bluebeam converts polyline segments to arcs.
- **Drops/rises:** OST/STACK/Procore expose a per-segment **Drop/Run** box with a condition-level default ("Add Length"); Bluebeam a single **Rise/Drop** field per markup; AutoBid uses explicit commands (Add-Drop And Rise, Vertical Run Only, Change Elevation). Avoid STACK's failure mode where ending the run silently adds a drop and correcting it deletes the run.
- **Per-run properties dialog:** PlanSwift hotkey **2** opens Linear Properties before drawing; STACK auto-opens the right panel when a takeoff requires inputs; QuoteSoft lets you change gauge/joint/seam/hanger/liner in the takeoff panel mid-run; Canaveral shows AI-suggested size and accepts on **hold Q**.
- **Fitting-first alternative:** FastEST/QuoteSoft place fittings then auto-fill duct/pipe between them (Auto Connect / Auto Duct) — worth supporting as a second mode.
- **Sidebar/legend:** Bluebeam Legends and Markups List with custom columns (one tool per size, grouped by Subject); Countfire recommends one colour per system and displays size labels on the drawing.
- **Multi-condition draw-once:** OST's patented Multi-Condition Takeoff (draw once, populate several conditions) is a pattern estimators expect for pipe + insulation + hangers on the same run.
- **Review posture for AI:** surface low-confidence runs, keep every auto-generated item editable, and show provenance back to the sheet (DuctIQ, Civils.ai, ConstructConnect guidance).
