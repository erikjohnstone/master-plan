## Bottom line

One new AC-WW rooftop unit replaces one existing untagged rooftop unit. The
populated equipment schedule has one row. Its controller diagram defines
14 unique integration points: 4 AI, 7 DI, 2 AO and 1 DO. These are factory-controller
points exposed to the BMS, **not a verified count of field-wired I/O channels**.

One existing thermostat is removed. One new wall-temperature device is provided
for the pump-station interior served by AC-WW. No CO2 sensor or smart-thermostat
designation is present. There are no populated control-valve, damper or actuator
schedules, and no full written operating sequence in the supplied PDF.

The audit retains differing power labels, differing curb minimums, and an
inconsistent thermostat/sensor symbol. It does not resolve them by guessing.

## 5. Verification and limitations

All eight pages were reviewed visually and their complete native text read.
MuPDF 1.27.2.2 and Poppler 26.03.0 were independently run against the unchanged
source. The ledger checks **242 bounded assertions / 484 engine checks**, including
sheet identities, issue dates, view scales, bar labels, all populated table cells,
column headers, each point label/description, and supporting notes. Normalized
performance values are also checked against their raw source cells.

Seven validator tests passed: the real record, plus deliberately wrong schedule
value, point tag, normalized value, column region, total point count and missing
page. This tests rejection behavior; it is not an extraction-accuracy benchmark
for the production engine.

Two important non-text exceptions are disclosed:

- The new T and engineering logo are graphical and separately checked in both
  rendered views; native text corroborates the sensor note and firm imprint.
- The angled H-501 curb note is fragmented by Poppler. Both engines locate 16;
  “minimum,” units and full wording were checked visually in both renders.

The JSON retains page/region coordinates and the verification report retains
each engine's word IDs and raw region text. Parser agreement verifies the
bounded text; visual review and cross-sheet reconciliation support quantities
and relationships. It does not make unavailable source information known.
